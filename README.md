# vibe-agent

Образ агента Hermes для сообщества Podpiwas coders: стандартная песочница kagent плюс наш `SOUL.md`, личность и правила агента.

- `SOUL.md` — системный промпт. Hermes читает его из `~/.hermes/SOUL.md`.
- Сборка: каждый пуш в `main` публикует образ в GHCR. Digest образа выводится в итогах запуска Actions.
- `vibe-control` подставляет образ в `AgentHarness` по digest: Substrate принимает только образы, закреплённые по digest.

Образ публичный: Substrate скачивает образы агентов без авторизации. Секретов здесь нет и быть не должно.

Изменение `SOUL.md` доходит только до новых агентов. Работающий агент получит его, когда его пересоздадут.
